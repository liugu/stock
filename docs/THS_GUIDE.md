# 同花顺自动化交易使用指南

## 快捷键说明

### 常用快捷键
| 快捷键 | 功能 |
|--------|------|
| F1 | 买入股票 |
| F2 | 卖出股票 |
| F3 | 查看个股行情 |
| F4 | 查看持仓 |
| F5 | 查看账户资金 |
| F6 | 查看自选股 |
| F10 | 公司资料 |
| Ctrl+T | 打开交易窗口 |
| Ctrl+Z | 撤单 |
| Esc | 返回/取消 |

### 输入股票代码
直接输入6位数字 + Enter，如：
- 输入 `603533` + Enter → 查看掌阅科技
- 输入 `000001` + Enter → 查看平安银行

### 买入流程（F1）
1. 按 F1 打开买入窗口
2. 输入股票代码
3. Tab 切换到价格框，输入价格
4. Tab 切换到数量框，输入数量（必须是100的整数倍）
5. Enter 或点击"买入"确认

### 卖出流程（F2）
1. 按 F2 打开卖出窗口
2. 输入股票代码
3. Tab 切换到价格框，输入价格
4. Tab 切换到数量框，输入数量
5. Enter 或点击"卖出"确认

## 安全提示

⚠️ **重要注意事项**

1. **紧急停止**：将鼠标移动到屏幕左上角可立即停止所有自动化操作
2. **手动确认**：建议在下单前手动检查价格和数量
3. **测试模式**：先在模拟账户测试
4. **权限检查**：确保已开通自动化交易权限
5. **风险控制**：设置合理的止盈止损线

## 监控持仓

### 配置止盈止损
在脚本中修改配置：
```python
CONFIG = {
    'stop_loss_pct': -3.0,   # 止损比例 -3%
    'take_profit_pct': 10.0, # 止盈比例 +10%
    'monitor_interval': 30,  # 监控间隔 30秒
}
```

### 实时监控
脚本会定期检查持仓盈亏：
- 价格低于止损线 → 自动卖出 + 蜂鸣器提醒
- 价格高于止盈线 → 自动卖出 + 蜂鸣器提醒

## 常见问题

### Q: 脚本无法连接同花顺？
A: 确保同花顺已启动，标题栏包含"同花顺"字样

### Q: 快捷键无效？
A: 检查同花顺是否置顶，尝试手动点击功能按钮

### Q: 输入失败？
A: 确保输入框已激活，使用Tab键切换焦点

### Q: 如何紧急停止？
A: 快速将鼠标移到屏幕左上角
