# 增强版数据适配器使用说明

## 已集成的数据源

| 数据源 | 稳定性 | 特点 | 状态 |
|--------|--------|------|------|
| **Baostock** | ⭐⭐⭐⭐⭐ | 免费、稳定、历史数据全 | ✓ 已集成 |

## 安装依赖

```bash
pip install baostock efinance akshare
```

## 使用方法

### 1. 获取历史数据（自动切换数据源）

```python
from instock.core.crawling.data_adapter_enhanced import get_stock_hist

# 获取平安银行历史数据
df = get_stock_hist(
    symbol='000001',        # 股票代码
    start_date='20260101',  # 开始日期 YYYYMMDD
    end_date='20260531',    # 结束日期 YYYYMMDD
    adjust='qfq'            # qfq=前复权, hfq=后复权, none=不复权
)

print(df.head())
```

### 2. 获取实时行情（自动切换数据源）

```python
from instock.core.crawling.data_adapter_enhanced import get_stock_spot

# 获取A股实时行情
df = get_stock_spot()
print(f"共获取 {len(df)} 只股票")
```

### 3. 检查数据源可用性

```python
from instock.core.crawling.data_adapter_enhanced import get_available_sources

sources = get_available_sources()
# {'baostock': True, 'efinance': True, 'akshare': True}
```

### 4. 单独使用某个数据源

```python
from instock.core.crawling.data_adapter_enhanced import (
    stock_zh_a_hist_baostock,
    stock_zh_a_hist_efinance,
    stock_zh_a_hist_akshare
)

# 使用 Baostock
df = stock_zh_a_hist_baostock('000001', '2026-01-01', '2026-05-31')

# 使用 efinance
df = stock_zh_a_hist_efinance('000001', 'daily', '20260101', '20260531')

# 使用 AkShare
df = stock_zh_a_hist_akshare('000001', 'daily', '20260101', '20260531', 'qfq')
```

## 数据源优先级

### 历史数据
```
Baostock → efinance → AkShare
```
Baostock 最稳定，优先使用

### 实时行情
```
efinance → AkShare → Baostock
```
efinance 实时性最好，优先使用

## 数据字段说明

历史数据返回字段：
- 日期
- 开盘、收盘、最高、最低
- 成交量、成交额
- 振幅、涨跌幅、涨跌额
- 换手率

## 注意事项

1. **网络环境**：当前环境网络不稳定可能导致API调用失败
2. **数据延迟**：实时行情有几分钟延迟
3. **频率限制**：避免过于频繁调用，可能被限流
4. **交易日**：非交易日无实时数据
