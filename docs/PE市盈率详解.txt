================================================================================
市盈率三种类型详解
================================================================================

一、三种市盈率定义
================================================================================

【静态市盈率】PE（静）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
计算公式: 当前股价 / 上年度每股收益（EPS）

数据来源: 上年度年报净利润
更新频率: 年度更新（年报发布后）

优点:
  ✓ 数据真实可靠（已审计）
  ✓ 稳定，不会频繁变化
  ✓ 适合成熟稳定企业估值

缺点:
  ✗ 滞后性强（最多滞后1年）
  ✗ 不能反映最新业绩变化
  ✗ 不适合业绩快速增长或下滑企业

适用场景:
  - 业绩稳定的成熟企业
  - 银行、公用事业等传统行业
  - 年报刚发布时参考


【动态市盈率】PE（动）⭐ 当前代码使用
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
计算公式: 当前股价 / 预测今年每股收益

数据来源: 分析师预测或季度业绩推算
更新频率: 随股价和业绩预测实时变化

优点:
  ✓ 前瞻性，反映未来预期
  ✓ 适合高成长企业估值
  ✓ 动态反映市场预期

缺点:
  ✗ 预测数据可能不准
  ✗ 波动较大
  ✗ 分析师预测可能偏差

适用场景:
  - 高成长企业
  - 创业板、科创板
  - 业绩快速增长期

⚠️ 注意: 当前代码使用的是动态市盈率！


【TTM市盈率】PE（TTM）⭐ 最推荐
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
计算公式: 当前股价 / 过去12个月每股收益

数据来源: 最近4个季度净利润总和
更新频率: 季度更新

优点:
  ✓ 反映最近真实业绩
  ✓ 不受季节性影响
  ✓ 国际通用标准
  ✓ 比静态更及时，比动态更可靠

缺点:
  ✗ 仍是历史数据
  ✗ 不能反映未来预期

适用场景:
  - 所有企业（最通用）
  - 国际投资分析
  - 主流推荐指标


================================================================================
二、对比示例
================================================================================

假设飞亚达数据：
  - 2025年报EPS: 0.22元
  - 最近4个季度EPS: 0.21元
  - 分析师预测2026年EPS: 0.18元
  - 当前股价: 23.06元

计算结果：
  - 静态PE = 23.06 / 0.22 = 104.8倍
  - 动态PE = 23.06 / 0.18 = 128.1倍
  - TTM PE = 23.06 / 0.21 = 109.8倍

实际数据（2026-05-28）：
  - PE（动）: 107.1倍 ← 当前使用

四、如何选择使用？
================================================================================

【推荐使用 TTM市盈率】

理由:
  1. 反映最近真实业绩，数据可靠
  2. 剔除季节性影响，更稳定
  3. 国际通用标准，便于对比
  4. 既不太滞后，也不过激进

【特殊场景】

使用静态PE:
  - 银行、保险等金融股
  - 业绩极其稳定的企业
  - 年报刚发布时

使用动态PE:
  - 高成长科技股
  - 创业板、科创板
  - 业绩快速增长期

避免使用:
  - 亏损企业（PE为负，无意义）
  - 业绩大幅波动企业
  - 周期性行业（需结合PB）

================================================================================
七、实际应用建议
================================================================================

1. 优先使用TTM市盈率
2. 结合PE、PB、PS等多个指标
3. 对比行业平均水平
4. 考虑企业成长性（PEG指标）
5. 关注业绩变化趋势

【完整估值公式】
合理PE = 行业平均PE × 增长率调整系数

示例:
  飞亚达行业平均PE: 25倍
  预期增长率: 5%
  调整系数: 1.2
  合理PE = 25 × 1.2 = 30倍

当前PE: 107倍 >> 30倍 → 高估
